# 🏛️ Risco Rico — Финтех-платформа b2b-аудита РКО

Независимый интеллектуальный сервис для предпринимателей, защищающий оборотный капитал от скрытых комиссий, капканов в тарифах и скрытой дани ТОП-15 банков РФ.

## 🚀 Технологический стек
* **Frontend:** HTML5 / CSS3 / JavaScript (Адаптирован под премиальные стандарты)
* **Backend & Automation:** Python 3.10+ / pyTelegramBotAPI
* **Cloud Infrastructure:** Render Cloud (Автономное фоновое вещание 24/7)

## 🤖 Структура экосистемы
1. **Интерактивный калькулятор:** `risco-rico.netlify.app` — моментальный расчёт потенциального ущерба.
2. **Робот-аудитор:** `@rko_RRhelper_bot` — автономный парсинг мелкого шрифта договоров под конкретную нишу за 30 секунд.

## 🛡️ Юридический статус
Платформа функционирует строго в соответствии с законодательством РФ, является интерактивным демонстрационным симулятором и не осуществляет сбор, хранение или обработку персональных данных пользователей (152-ФЗ).
